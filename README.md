# Sri Lanka Forest Loss Analysis (2001–2025)

A Google Earth Engine script using Hansen/UMD Global Forest Change data to track annual forest loss across Sri Lanka and its districts.

## Features
- **National Trends:** Annual forest loss chart (2001–2025).
- **District Rankings:** Total historical loss and recent loss (2021–2025) breakdowns.
- **District Close-ups:** Customizable single-district analysis (default: Hambantota).
- **Interactive Map:** Color-coded visualization of forest loss over time (yellow = 2001 to purple = 2025).

## How to Run
1. Open [Google Earth Engine Code Editor](https://code.earthengine.google.com/).
2. Paste the contents of `sl_forest_loss_starter.js`.
3. Click **Run**.
